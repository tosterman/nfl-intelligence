# Prospective joint-score shadow evaluation

Freeze both priors and solver from the fixed joint-score evaluation without further parameter selection. Generate candidate and reference joint distributions only for games whose verified public point forecast matches the local retained snapshot and whose kickoff is still in the future. Archive the complete matrices, model means, game identities, kickoff times, source/code/protocol hashes and generation time. This is a separate research track; the public forecast engine remains unchanged.

A generation timestamp or local file is not publication proof. Eligibility requires independently fetching the exact compressed archive from its immutable GitHub commit, verifying its compressed and decompressed hashes, and retaining the retrieval time and GitHub HTTP date. Both generation and verified retrieval must precede the game's recorded kickoff. Preserve the first eligible published shadow per game; never choose the best revision after the result. A changed kickoff/team identity requires separate reconciliation, not silent reuse.

When verified final results become available, score every eligible game for both distributions using the frozen joint/margin/total log scores, CRPS and three-outcome Brier. Publish exclusions and missing results. Retain full-precision distributions; do not regenerate from revised data at grading time. Report small sample limitations and whole-week uncertainty only when enough clusters exist. Do not infer profitability, model superiority or current-rule tie calibration from a single week. The archive is research evidence, not a recommendation or promoted product feature.
