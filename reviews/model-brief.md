# Opening model explanation

The opening read now identifies the largest contribution supporting the model's
expected margin and the strongest contribution in the opposite direction.
Previously it listed the three largest absolute contributions, which could omit
every opposing factor. A model with no opposing displayed contribution does not
receive an invented counterargument. Near-zero margins receive no fabricated
directional advantage.

The component verifies that all finite contribution values reconcile to the
margin, allowing only their recorded three-decimal rounding tolerance. It links
to the complete contribution chart, whose heading is now an accessible fragment
target. This changes explanation selection, not numerical predictions.

Three tests passed: counterweight outside the top three; away/no-counter/tied
and invalid-accounting cases; and reconciliation for every current forecast.
TypeScript checking passed. A real 390px Chromium visit to ATL/PIT verified the
brief, no horizontal overflow, and focus moving to the contribution heading
after activating the evidence link. The mobile screenshot was reviewed; consent
was then declined for the retained unobscured capture.

advantage/counterweight portion of the planned brief, not a completed integrated
