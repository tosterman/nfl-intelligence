Its structured Place record identifies Acrisure Stadium at 100 Art Rooney Ave, Pittsburgh, Pennsylvania. This is a stadium place link, distinct from the directions page's many parking-lot coordinate links.

The place point is inside the previously retained OSM way 24722790 bounds. The OSM bounds midpoint is 40.44672985, -80.0158181; the NWS point lookup confirms Pennsylvania and hourly grid PBZ/77,66. That midpoint is derived from OSM, not copied from a parking destination or substituted from a team city.

`acrisure-linked-place-candidate.json` retains the selected factual place fields, official-link assertion, full-page digests, original OSM response identity, bounds containment and NWS response identity. Original OSM/NWS JSON is compressed under its digest. Full official/Waze HTML remains in ignored local recovery files; the public report does not reproduce photos, map images or embedded credentials.

This advances the prior investigation but does not change production coverage. The existing validator requires matching OSM address tags, which this stadium lacks. A new narrowly defined reconciliation rule must verify the official link's intended venue, name/street/locality/state agreement, finite point containment, OSM geometry and attribution, NWS state, and retained evidence consistency. It must not allow a supplementary place record to override conflicting OSM address tags. Candidate status remains explicit until that rule and its rejection tests are reviewed.

An independent source review verified both HTML digests, the exact official anchor, the selected place fields, original OSM/NWS response digests, unique stadium feature, bounds midpoint and NWS grid. It supports a distinct official-linked-place reconciliation path for a stadium-vicinity lookup.
