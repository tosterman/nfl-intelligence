# Prior quarterback passing features — September 10, 2026

Built an experimental feature matrix for the fixed 24-hour pregame cutoff in the 2025 role audit. Of 570 team-games, 538 have prior passing history for the listed quarterback, 28 lack a usable role and four have a role but no qualifying history in the acquired 2024–25 files. Missing history remains null, not an asserted average player. This measures feasibility, not prediction improvement.

Source files are nflverse [2024 weekly player statistics](https://github.com/nflverse/nflverse-data/releases/download/stats_player/stats_player_week_2024.csv) and [2025 weekly player statistics](https://github.com/nflverse/nflverse-data/releases/download/stats_player/stats_player_week_2025.csv). Both hashes matched release metadata and are recorded in `quarterback-feature-audit.json`. These use the current stats_player release schema, not the older player_stats release. The full files remain in ignored release-recovery storage. Derived data is attributed to nflverse under [CC BY 4.0](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md).

## Defined features

Passing dropbacks here mean attempts plus sacks; scrambles and designed runs are excluded. Net passing yards equal passing yards plus the source's negative sack-yard total. Records are weighted with a 90-day half-life. Net yards per passing dropback are shrunk with 200 weighted-dropback equivalents toward the contemporaneous prior-only QB population mean. Sack rate is weighted sacks divided by weighted passing dropbacks. These fixed research settings have not been tuned for predictive performance. Game count, weighted dropbacks and most recent contributing game time accompany each available feature.

The source schedule supplies game identity, participant teams and Eastern-time kickoff. A source game must have a result and kickoff more than 24 hours before the feature cutoff. That embargo is a conservative publication proxy: no actual completion or per-stat publication timestamps are present, and current historical statistics may include later corrections. Therefore this is not a verified vintage replay. Passing metrics do not isolate individual causal value from receivers, line, scheme or opponents, and this experiment does not yet measure rushing value.

Six deterministic tests check sack-yard signs, missing history, future/cutoff embargo exclusion, duplicate/team mismatches, future-stat perturbation and exact two-player decay/shrinkage arithmetic. Independent review verified source hashes, unique team-game counts, finite metrics and embargo compliance, finding no material defect. The output excludes recorded game QB IDs and retrospective role agreement labels from candidate features. Actual target outcomes must remain evaluation labels, never inputs. The next required step is a time-separated comparison against the existing model, retaining missingness and role uncertainty. Production forecasts remain unchanged.
