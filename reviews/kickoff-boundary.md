# Open-tab kickoff boundary

A real local browser reproduction found that current sportsbook comparisons remained visible at kickoff plus 100 milliseconds when the next 15-second clock poll had not fired. Both MarketPanel and MarketCard used that polling clock. The fix adds a separate kickoff timer that updates the clock at the deadline, clears on unmount or kickoff change, caps browser timeout length, and rearms when a long timeout or early callback occurs. Existing periodic and visibility-change updates remain.

The initial browser test failed on the retained SF/LA edition with real stored eligible quotes. After the change, Chromium and WebKit at 320px verified both the matchup panel and slate card: eligible quotes remain at 100ms before kickoff; with simulated time held at 100ms after kickoff, the UI closes comparisons after React renders without advancing to another polling interval. The selector and cross-book comparison disappear from the detail panel; the card reads Pregame closed. Historical observations retain their separate historical labeling. No page errors were observed.

The browser script uses stable game identity rather than a timestamp that disappears on closure. Auto-retrying DOM assertions accommodate React's asynchronous rendering. This is not a measured real-time 100ms rendering guarantee. Reproduce with `python scripts/check_kickoff_boundary.py`; it requires localhost:3000, the retained SF/LA edition and matching eligible stored odds. It is a live-data drill, not a self-contained CI fixture.

Type checking and all 116 application tests passed. Independent review found no blocker in cleanup, long timeout handling or normal-clock behavior. System-clock jumps remain governed by the periodic/visibility checks and can introduce polling latency; if time moves backward after the one-shot timer completes, that timer does not rearm. This change addresses normal progression through kickoff, not arbitrary clock tampering. Source eligibility still depends on the supplied clock, and in-play odds are not introduced.
