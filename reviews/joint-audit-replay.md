# Reproducible frozen joint-score research

Run `python scripts/replay_joint_audits.py` after installing requirements.txt. The runner recreates both 285-game event and settlement audits in a temporary workspace using retained schedule, forecast, source-code and prior-matrix bytes. Every compressed and decompressed input is hashed. All report fields, record counts, labels and fingerprints must agree; floating-point results use relative tolerance 1e-10 and absolute tolerance 1e-12. No live schedule/odds request is made, and production data files are not rewritten.

The retained local schedule is 2,178,321 bytes, SHA-256 `b0b01f911efc41ad05259f26938091678afde4790541c9d99268843d5c08320f`. It matches both committed audit inputs and the earlier joint-score evaluation. The 754,780-byte site artifact matches the two newer audits. The original schedule retrieval time is unavailable; the manifest records provider attribution and CC BY 4.0 licensing without inventing an acquisition date.

Initial clean Linux and Windows attempts correctly failed strict frozen-prior checks: numerical backends produced different low-order covariance bits, and one Git-normalized script differed only in CRLF encoding. Exact source bytes are now restored only after confirming the current code is identical except line endings. The runner independently refits and verifies priors/fit values numerically, then explicitly supplies the archived, hash-verified prior matrices to the unchanged audit code. This is numerically verified refitting plus replay from exact archived priors, not bit-for-bit cross-platform refitting. The original distributions, protocol hashes and audit results are unchanged.

[Hosted run 34525840318](https://github.com/tosterman/nfl-intelligence/actions/runs/34525840318) passed on Ubuntu and Windows. Independent review ran both local audits and both replay tests, and found no material defect. Tests reject corrupted inputs, changed report structures, nonfinite values and materially different numerical results. Exact expected-report hashes may reflect checkout line endings; parsed content and embedded source/input fingerprints are the comparison authority.

The workflow is manually dispatched, read-only and independent of publication. It does not prove prospective accuracy, betting profitability, bitwise portability or reproducibility of every other experiment in this repository.
