# Private odds archive — 2026-09-10

Production odds acquisitions now write normalized feed snapshots to the private Vercel Blob store `nfl-odds-history`. Each compressed JSON envelope identifies the provider and schema version, retaining acquisition and bookmaker market timestamps. The filename contains the acquisition timestamp and SHA-256 of the uncompressed envelope. Uploads explicitly disable overwrites and random suffixes. This is normalized-content evidence, not the original provider response bytes or tamper-proof storage.

The store is connected to production and development; the application writes only when VERCEL_ENV is production. No raw-history download endpoint or public Git archive is provided. Credentials remain in ignored environment files and platform environment variables. Provider terms permit storage and application display while restricting standalone raw-data redistribution: https://the-odds-api.com/terms-and-conditions.html .

This is best-effort, traffic-driven capture within the existing six-hour odds cache, not scheduled closing-line collection. A failed archive write emits a generic server error, preserves usable quotes, and does not retry the same acquisition. The SDK upload has a five-second abort signal. Gaps are possible; there is no backfill or complete-history claim. Scheduled collection, retry/gap monitoring, bookmaker settlement rules and prospective forecast matching remain prerequisites for credible CLV reporting. No model improvement or profitability is implied by storing odds.
