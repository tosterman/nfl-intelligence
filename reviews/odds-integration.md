# Real odds integration — 2026-09-10

The user-provided The Odds API credential was found in ignored `.env.local`, verified with a successful NFL odds request, and installed as a sensitive production/preview Vercel environment variable. The initial request cost three credits; the account then reported 497 remaining. No credential or credential-bearing URL is emitted in application logs or client props.

The production integration uses a server-only Next data-cache function shared by slate and game pages, with a six-hour revalidation interval. Cache identity contains a one-way credential fingerprint. This is quota-conscious snapshot access, not continuous real-time odds. Four successful three-market requests per day would nominally cost 360 credits in 30 days for one cache; local development, previews, cache misses/evictions and revalidations can add calls. No hard monthly budget enforcement or paid upgrade is claimed. A provider failure is cached as unavailable for up to six hours, which limits repeated quota use but delays outage recovery.

Only exact team identities and kickoff instants match. Final/started games, future/stale acquisitions, stale/future quote timestamps, duplicate events, ambiguous bookmaker keys, malformed opposing outcomes, inconsistent spread points and inconsistent totals fail closed. Individual missing markets do not erase other valid ones. Quotes expire at kickoff or after six hours; client timers and visibility changes re-evaluate availability. Model comparisons are withheld when the existing model/source freshness checks fail.

The slate shows a named reference-book spread (FanDuel when available, otherwise the first alphabetic eligible book); it is not a best-price or consensus assertion. Game detail lets readers select a bookmaker and displays moneylines, spreads, total prices, quote timestamps and deterministic model differences. The normalized two-sided market probability does not verify bookmaker tie/overtime settlement. No validated edge, ROI, stake or CLV assertion is made. The numerical prediction engine and prospective forecast artifact are unchanged. This first feed integration does not archive odds history; durable snapshots, scheduled publishing and CLV remain follow-up work.

Independent review found and resolved the initial five-minute kickoff tolerance bug, ambiguous duplicate bookmakers and unsupported settlement wording. Five new parser tests passed, alongside existing TypeScript tests. The local browser rendered real FanDuel and DraftKings quotes and selection changed the displayed bookmaker/moneyline. Browser selection emits only `market_book_selected`, after analytics consent, with no user-entered text.
