# Weekly forecast change briefing

The slate now includes a collapsed, keyboard-accessible briefing for the selected week. It compares each displayed forecast with its immediate retained predecessor only when game context, ordered generation times, finite predictions and model/source identity support that comparison. Comparable rows are ranked by absolute margin change and then win-probability change. Model-definition changes and first retained forecasts appear separately. The leading reconciled contribution is statistical accounting, not an injury/weather or other causal explanation.

Every item links to the matchup's `forecast-changes` section. Generation times are explicitly distinguished from publication evidence and from a reader's previous visit. The briefing covers the whole selected week, independently of team-search/card filters. Unavailable comparisons are grouped separately with retained-history links, including games whose active snapshot was withheld. It does not invent deltas for legacy context-less records.

Independent source review caught the history-present/current-snapshot-missing omission and insufficient contribution display precision; both were corrected. A focused regression also caught binary floating-point rounding at the smallest displayed contribution. Five tests cover ranking/direction, first/model/unchanged states, changed context, timestamps, missing identity, duplicate current entries, nonfinite values, retained-history access and contribution rendering. All 105 application tests passed before the final grammar-only correction; the five affected tests pass afterward. TypeScript validation passed.

`weekly-changes-browser.json` records real local Week 1/2 disclosure interactions in Chromium and WebKit at 320px, with no overflow. The current edition provides unavailable/empty states, not a real comparable revision. `weekly-changes-fixture-browser.json` records isolated populated comparison, first-forecast and model-change cards in both engines at 320px and 1440px, using the actual application styles. The fixture changed only the browser DOM; no forecast files were modified. The final 320px Chromium screenshot was visually inspected.

An initial fixture harness produced all screenshots but stalled before returning; it was explicitly stopped and rerun with per-case result persistence and teardown logging. Final teardown completed in both engines. A fixture-file decoding problem on Windows was corrected by reading its UTF-8 explicitly before the final visual check. These are local checks, not verified public availability or real-user acceptance.
